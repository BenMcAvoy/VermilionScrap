# VermilionScrap

VermilionScrap is a Windows C++ Scrap Mechanic overlay experiment built around Win32 and Dear ImGui. The current UI draws a small status watermark and provides the base for further game-overlay research.

## Build

Open `VermilionScrap.sln` in Visual Studio and build the x64 configuration. The project uses vcpkg manifest dependencies.

## Status

This repository is an early modding/reverse-engineering scaffold. The code is tied to Scrap Mechanic internals and is not a complete or supported mod.
